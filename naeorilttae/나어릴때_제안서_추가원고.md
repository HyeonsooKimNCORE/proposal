## S21 | 메타 계정 구조 (교체)
- layout: diagram-tree (캠페인 3개 가로 배치 + 하단 측정 박스)
- section: 03 운영 전략
- headline: 새 고객, 돌아올 고객, 테스트를 나눠서 운영합니다
- body:
  - 캠페인 A — 신규 고객 (예산 60%)
    - 방식: Advantage+ 쇼핑 캠페인 또는 수동 캠페인 비교 후 선택
    - 타겟: 30~50대 여성 중심, 넓은 타겟에서 메타 AI가 구매 가능 고객 탐색
    - 소재: 제품력 중심 (번짐 테스트, 라인 시연, 브랜드 향수)
    - 지표: CPA, 구매 ROAS
  - 캠페인 B — 리타겟팅 (예산 25%)
    - 방식: 카탈로그 광고 (카페24 상품 정보 연동, 본 상품을 다시 보여줌)
    - 타겟: 자사몰 방문 30일, 장바구니 7일, 구매자 제외
    - 소재: 혜택 중심 (1+1, 슈퍼적립, 기간 한정)
    - 지표: 구매 ROAS
  - 캠페인 C — 소재 테스트 (예산 15%)
    - 새 소재를 같은 조건으로 먼저 검증
    - 이긴 소재만 캠페인 A로 이동 (S26 위닝 소재 운영과 연결)
  - 확장 옵션: 파트너십 광고
    - 실구매 리뷰어·뷰티 크리에이터 게시물을 광고로 집행
    - 경쟁사(노에트 등)도 활용 중인 방식 〔확인〕크리에이터 섭외비 별도 여부
  - 측정 기반
    - 메타 픽셀 구매 이벤트 점검 + 전환 API 연동
    - 광고 링크 UTM 규칙 통일
    - GA4 설치로 채널 간 성과 비교

## S22A | 소재 예시 ① 영상 스토리보드
- layout: storyboard-5 (컷 5개 가로 배치, 각 컷에 화면 설명 + 자막)
- section: 03 운영 전략
- headline: 15초 안에 '안 번진다'를 눈으로 보여줍니다
- sub: 컨셉 1 번짐 테스트 · 9:16 릴스·스토리 · 캠페인 A(신규)
- body:
  - 컷1 (0~2초) 훅
    - 화면: 손등에 아이라이너로 라인 한 줄
    - 자막: "이거, 진짜 안 번질까?"
  - 컷2 (2~5초) 컬러
    - 화면: 4컬러 스와치 나란히
    - 자막: "엣지홀릭 브러쉬 4컬러"
  - 컷3 (5~9초) 테스트
    - 화면: 물을 뿌리고 손가락으로 문지르기
    - 자막: "물 묻히고, 문질러도"
  - 컷4 (9~12초) 사용
    - 화면: 눈꼬리 라인을 한 번에 빼는 클로즈업
    - 자막: "꼬리 라인은 한 번에"
  - 컷5 (12~15초) 증거 + 행동 유도
    - 화면: 리뷰 캡처 + 제품
    - 자막: "번지지 않아서 더울 때도 열심히 사용했어요" ★4.7 리뷰 1,154건
    - 버튼: 1+1로 만나보기
  - 하단 주석: 컷3은 실제 촬영 결과로만 사용합니다. 결과가 기대와 다르면 컷3을 '하루 착용 전후' 비교로 바꿉니다.
- image: s22a_storyboard.png (디자인팀 콘티 또는 AI 보정 컷)
- note: 기존 제품 컷 + 간단 촬영으로 제작 가능. 제작비 추가 없음.
