# 작업지시서 — 나어릴때 제안서 v2 보충 (Claude Code용)

---

## 0. 사용 방법 (김현수 팀장용)

1. 기존 작업 폴더(`naeorilttae_deck/`)에 아래 파일을 넣습니다.
   - `나어릴때_제안서_v2.pptx` → `input/` 폴더 (직접 워싱한 파일)
   - `나어릴때_제안서_추가원고.md` → 폴더 최상위
   - `작업지시서_v2보충.md` (이 파일) → 폴더 최상위
   - 새 이미지가 있으면 `assets/`에 추가 (5장 참고)
2. Claude Code에 입력합니다: **`작업지시서_v2보충.md 읽고 1단계부터 진행해줘`**
3. 1단계 보고를 확인하고 **`진행해`**라고 하면 끝까지 만듭니다.
4. 결과물: `output/나어릴때_제안서_v3.pptx`

---

## 1. 목표

**v2 파일을 기준으로** 추가 원고의 장표를 끼워 넣어 v3를 만든다.

- v2는 사람이 직접 문구를 다듬은 파일이다. **추가 원고에 해당하지 않는 기존 장표는 글자 하나도 바꾸지 않는다.**
- 새 장표는 템플릿 레이아웃이 아니라 **v2 안의 비슷한 장표를 복제해서** 만든다. v2에서 사람이 고친 디자인(여백, 글자 크기, 색 사용)을 그대로 따르기 위해서다.
- 처음부터 다시 만들지 않는다.

## 4. 표현 수정 (1단계에서 보고만, 승인 후 적용)

아래는 v2에서 고칠 후보다. **1단계에서 현재 문구와 바꿀 문구를 표로 보여주고, 사용자가 승인한 항목만 고친다.**

| 장표 | 현재 | 수정안 |
|---|---|---|
| S15, S16 | 10월 대행 이관 즉시 | 11월 대행 이관 즉시 |
| S06 | 월 40건+ | 월 20건 내외, 최대 50건 |
| S06 | 전담 TF | 전담 담당자 |

| S12 | 유입 방어선 붕괴 | 광고 구좌 공백 |
| S12 헤드라인 | 경쟁사에 전면 노출 방치 중 | 경쟁사가 차지하고 있음 |
| S13 | ▶ 통합 가격 통제(MAP 관리) 시급 | ▶ 판매처 가격 정책 점검 권장 |

- 문구가 표와 정확히 같지 않으면 고치지 않고, "찾지 못함"으로 보고한다.
- 글자만 바꾸고 서식(굵기, 색, 크기)은 그대로 둔다.

## 6. 작업 단계

### 1단계 — 분석 (끝나면 멈추고 보고)

1. `input/나어릴때_제안서_v2.pptx`를 열어 장표 목록(번호, 헤드라인, 사용 레이아웃)을 정리한다.
2. 3장의 "찾을 헤드라인"으로 기준 장표 위치를 확인한다. 못 찾은 장표가 있으면 보고한다.
3. 복제 기준 장표의 구성(도형 개수, 표 크기, 글자 크기, 색)을 정리한다.
4. 4장의 표현 수정 후보를 현재 문구와 함께 표로 보여준다.
5. 없는 이미지 목록을 정리한다.
6. 보고하고 **사용자 확인을 기다린다.** (표현 수정은 항목별로 승인받는다)

### 2단계 — 제작

1. v2를 복사해 `output/나어릴때_제안서_v3.pptx`로 저장하고, 이 파일만 수정한다. `input/`의 원본은 건드리지 않는다.
2. 새 장표는 복제 기준 장표를 **복제(이미지·도형·표 포함)한 뒤 텍스트와 표 내용만 바꿔서** 만든다.
   - 표의 행·열 수가 다르면 행·열을 추가·삭제하고, 기존 셀 서식을 복사해 맞춘다.
   - 카드 개수가 다르면(4 → 5, 2 → 3) 기존 카드를 복제해 간격을 균등하게 다시 배치한다.
3. 복제한 장표를 3장의 위치로 옮긴다 (슬라이드 순서 변경).
4. 상단 섹션 라벨은 `03 운영 전략` / `04 운영 방식`으로 맞춘다.
5. 페이지 번호가 텍스트로 들어가 있으면 전체 장표의 번호를 새 순서에 맞게 고친다.
6. 추가 원고의 `note`는 발표자 노트에 넣는다.
7. 승인받은 표현 수정을 적용한다.
8. S24(04 운영 방식 간지)의 소제목 목록에 '채널 운영 리듬'을 추가하고, S18(03 운영 전략 간지)의 소제목에 '소재 예시'를 추가한다. 간지 문구는 기존 형식에 맞춰 한 줄씩만 추가한다.

### 3단계 — 검수

1. LibreOffice로 PDF → 슬라이드별 PNG 변환 (`output/_qa_v3/`).
2. **새로 만든 장표와 수정한 장표만** 한 장씩 보고 확인한다.
   - 글자 넘침, 겹침, 빈 개체 틀
   - 복제 기준 장표와 여백·글자 크기가 같은지
   - 추가 원고의 문구·수치가 빠짐없이 들어갔는지
3. 기존 장표는 v2와 v3의 텍스트를 비교해, **승인한 수정 외에 바뀐 글자가 없는지** 확인한다.
4. `output/QA_v3.md`에 결과를 남긴다.

## 7. 규칙

- 최초 `작업지시서.md`의 7장(텍스트 규칙)과 8장(금지 사항)을 그대로 따른다.
- 추가 원고의 문구를 요약하거나 바꾸지 않는다.
- `〔확인〕` 표시는 노란 배경 하이라이트로 표시한다.
- 인스타그램 운영과 소재 제작에서 협력사·외주를 언급하지 않는다.
