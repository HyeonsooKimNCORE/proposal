## 4. 문장 원칙 (가장 중요)

이번 개편의 핵심은 **자연스러운 문장**이다. 원고 문장을 그대로 쓰되, 레이아웃 때문에 줄여야 하면 아래 원칙으로 줄인다.

- **보고서 톤, 번역투 금지.** "~를 진행합니다", "~에 대한", "~을 통해", "~하는 것이 핵심입니다" 같은 표현을 줄인다.
- **한 문장에 한 가지만.** 쉼표로 세 가지 이상 이으면 나눈다.
- **주어를 분명히.** "누가 무엇을 한다"가 보이게. 예: "판정 전에는 손대지 않음" → "판정 전에는 소재와 입찰을 바꾸지 않습니다"
- **제목은 결론 한 문장.** 30자 안팎, 마침표 없음. 제목만 읽어도 장의 결론을 알 수 있게.
- **숫자는 앞에.** "월 약 516만 원을 줄일 수 있습니다"처럼 숫자가 먼저 눈에 들어오게.
- **명사 나열형 금지.** "구조 정리, 셰프 파워링크, 카탈로그"처럼 명사만 나열하지 말고 동사로 끝맺는다. 단 표 안은 예외.
- 존댓말은 "~합니다/~입니다"로 통일. "~드립니다"는 광고주에게 무언가 줄 때만.

## 5. 레이아웃 원칙

| 항목 | 기준 |
|---|---|
| 제목 | 모든 내용 장에서 같은 위치·크기 (템플릿 기준) |
| 상단 라벨 | 과제 번호 표기: "① 소재", "② 판정 기준", "③ 비용 누수", "④ 상시 점검", "운영 조건" |
| 하단 띠 | 각 장의 결론 한 줄. 강조색 바탕, 흰 글씨 |
| 표 | 머리글 남색, 첫 열 연회색. 본문 10~12pt. 칸 안 줄바꿈은 단어 단위로 |
| 소재 자리 | 회색 박스(점선 테두리) + "소재 이미지 (디자인팀 제작)" + 비율 표기. 디자이너가 덮어쓸 수 있게 그룹으로 묶지 않음 |
| 여백 | 가장자리 0.5인치 이상, 요소 간 0.2인치 이상 |
| 차트 | 11장 사례 차트는 PowerPoint 기본 차트(편집 가능). 종료 전후 막대 색을 구분 |

**한글 줄바꿈:** 텍스트 상자가 좁아 단어 중간("집/중")에서 끊기면 안 된다. 상자 폭을 넓히거나, 띄어쓰기 위치에 줄바꿈(Shift+Enter)을 넣는다.

## 7. 품질 체크리스트

- [ ] 원고의 숫자가 하나도 바뀌지 않았다 (516만 원, 390만 원, 173개, 2.8배, 14일, 300회 등)
- [ ] 3장 금지 항목이 어디에도 없다
- [ ] 제목이 모두 결론형 한 문장이고 같은 위치에 있다
- [ ] 단어 중간 줄바꿈, 텍스트 넘침, 요소 겹침이 없다
- [ ] 회색 박스 6개(3·4장)가 있고 비율 표기가 맞다
- [ ] 7장 표 아래 계산 기준 캡션이 있다
- [ ] 12장 담당자 정보가 원고와 같다
- [ ] 템플릿 로고·푸터가 모든 장에 정상 표시된다
- [ ] PDF로 내보냈을 때 글꼴이 템플릿 글꼴로 나온다
