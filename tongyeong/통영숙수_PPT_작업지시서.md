## 2. 데이터 기준

- 모든 전환 지표는 **구매완료 전환수·구매완료 전환매출액** 기준. 총전환은 쓰지 않음
- ROAS = 구매 매출 ÷ 광고비
- 광고 성과는 **통영숙수 캠페인만** 집계. 3분기 = 2026년 7~9월, 10월 = 10월 1~14일
- 스마트스토어 통계, 판매 비중, 목표 ROAS·BEP, 예산 범위, 무료배송 기준은 **광고주 제공 수치**
- 예산안의 예상 ROAS는 **추정치**. 슬라이드에 "3분기·10월 실적 기반 추정"을 반드시 표기

## 3. 확정된 사실 (원고와 다르면 원고 우선, 원고에도 없으면 여기)

| 항목 | 사실 |
|---|---|
| 목표 / BEP | 구매완료 ROAS 450% / 300% (일부 상품 270%까지 허용되나 보수적으로 300%) |
| 4분기 예산 | 월 300~400만 원 (전략에 따라 변동 가능, 목표 달성 시 증액) |
| 판매 비중 | 7월~8월 초 물회 70%·전복죽 25% / 8월~현재 전복죽 95%·그 외 5% (스토어·자사몰 동일) |
| 스마트스토어 | 9월 방문 2,667·결제 130·전환율 4.9% / 10월 1~14일 방문 3,612·결제 82·전환율 2.3%, 디스플레이 광고 유입 74.9% |
| 무료배송 | 5만 원 이상 |
| 전복죽 | 장호준의 게우 통전복죽, 판매가 25,900원, 완도산 전복 3마리분과 내장, 밥솥 취사 13분, 1팩 2인분 |
| 생선구이 | 1팩 280g, 필렛 공정 가시 99.9% 제거, 48시간 숙성, 삼치 국내산·고등어 노르웨이산 |
| 쭈꾸미볶음 | 370g, 16,900원, 쭈꾸미 75%(외국산), 맵기 3단계, 100g당 당류 1g 미만 |
| 셰프 | 장호준 셰프. 통영 출신. IP(얼굴·이름·영상) 모두 사용 가능 |
| 백화점 | 2026년 7월 현대백화점 목동점·판교점 팝업 진행. **향후 팝업 예정 없음** |
| 프로모션 | 정해진 일정 없음. 11~12월 브랜디드 콘텐츠 검토 중 (프로모션 적용 가능) |

## 5. 꼭 지켜야 할 메시지 톤

- **정직하게:** 4분기 예상 ROAS(201~281%)가 BEP(300%)보다 낮다는 사실을 숨기지 않는다. 대신 "목표까지의 경로"로 12월 BEP 근접 → 1분기 BEP 이상 → 2분기 450%를 보여준다.
- **근거 우선:** 주장마다 숫자나 광고주 제공 자료를 붙인다.
- **광고주가 잘한 것 인정:** 셰프 IP 확보, 상품력(게우 통전복죽의 초록빛, 48시간 숙성), 지난여름 물회 성과.
- 문장은 짧게. 슬라이드 제목은 **메시지형 한 문장**(30자 이내 권장, 마침표 없음).
